    连接与执行说明

    连接地址：localhost:38471。每个目标文件都需要打开插件；同一设备复用绑定，CLI 仍区分文件。意外断线会持续重连；手动断开或停止重连后，需要点击重试或重新打开插件。断开连接保留绑定，取消此设备绑定会同时结束使用此绑定的其他文件会话。授权保存在 Figma 本机存储与项目的 .figma-agent 目录；清除存储或更换插件 ID 后需要重新绑定。暂停会在当前命令完成后停止接收；未确认结果的命令需要检查画布后继续。
