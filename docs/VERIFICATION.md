# 验证记录

验证环境：macOS、Node.js 26.8.1、Google Chrome。当前安装包版本 0.7.1；连接面板交互沿用 0.4.2。

## 真实操作

0.3.3 已在真实 Figma Design 文件中完成连接、文档读取，以及 Grok 图标的生成、复刻和导出。生成图由宿主 image_gen 返回；复刻稿包含 3 个可编辑矢量图层和独立背景。实际导出检查覆盖 1024、64、32 px；SVG 包含 3 条路径，没有嵌入位图。

结果见 [参考与复刻](showcase/grok.html)、[Figma PNG](showcase/grok-figma.png) 和 [SVG](showcase/grok.svg)。README 的对比截图由这些实际结果排版展示，并非 Figma 客户端窗口截图。

0.7.0 在已连接的 Figma 桌面插件上完成两次只读代码导出：390 × 556 的导出面板（节点 `3:6790`，React，6 个 SVG），以及 390 × 844 的照片首页（节点 `3:5112`，HTML，13 个 SVG 和 3 个 PNG）。两次均保存原生图层结构、实际 Figma 预览、素材、字体清单和代码文件；导出前后读取的设计一致。生成页面在 390 / 1440 px 浏览器视口下检查尺寸、素材加载和页面错误，并与 Figma 原图作视觉对照。

字体没有随包分发。实测环境缺少 Bodoni Moda、Noto 等原字体，字形和字重有差异；SVG 的描边及导出边界也需对照原稿调整。这些结果验证了代码交接链路，不代表像素级一致或已完成目标应用实现。

0.7.1 将代码交接入口统一为 `HANDOFF.md`，Skill 可通过 `--skills-dir` 安装到指定宿主目录。自定义目录安装与更新由隔离目录测试覆盖；其他 Agent 客户端尚未逐一实测。

## 本地回归

- `npx playwright test --config playwright.config.mjs tests/code.spec.ts`：新增代码预览场景通过，覆盖 390 / 1440 px、原始尺寸、图层位置、素材加载、单行文字和文本转义。浏览器验证保留在单独的 UI 测试入口，普通 Node 回归不依赖 Chrome。
- `npm run check`：类型检查、构建及 76 项 Node 回归，覆盖 HTTP / 队列、设计与几何合约、图片任务、代码交接、CLI 集成、skill 安装与授权存储。
- `npm run test:ui`：25 个 Chrome 场景通过，包含代码预览和既有插件 UI、图标预览，覆盖 260 / 368 / 640 px 面板、320 / 1280 px 预览、键盘、错误和恢复、localhost 实际 HTTP 传输。
- 持久化检查覆盖实际桥接服务的授权写盘、重启恢复、同名文件隔离、重复恢复请求、撤销授权、损坏/不可写存储。Chrome 场景覆盖重开面板、两个文件复用授权、服务重启恢复、超过六次失败后的持续重连、服务恢复后自动连接、手动停止与断开、取消在途请求及延迟响应隔离、暂停保留和不确定命令不重放。
- skill 安装检查使用独立目录，覆盖含空格和特殊字符的路径、预构建工具下载、重复安装复用、个人 skill 保留和备份升级、首次后台启动及配对引导、后续启动不换码、启动失败诊断与锁释放、macOS 临时目录别名入口。后台启动测试使用独立端口的 HTTP 子进程和真实 CLI 客户端；已有桥接复用通过真实桥接服务验证。
- 0.4.1 补充非安全上下文中的内嵌面板测试：0.4.0 在缺少 `crypto.randomUUID` 时启动失败，表单提交使 URL 跳到 `about:srcdoc?`；修复后同一场景成功绑定、保存授权，且不发生导航。另有启动错误注入，验证错误可见、键盘提交无法跳转成空白页。

- 原型命令通过 CLI → HTTP 桥接 → 插件执行器往返验证。定向回归覆盖交互读取/替换/清除、异步原生写入、目标和时长预检、悬停/拖拽/延时触发、弹簧/贝塞尔/方向动画、组件集约束、旧交互字段规范化及原生错误传播。开关示例通过脚本语法检查；夹具不播放 Figma 动画。

## 验证边界

Figma 主线程存储接口使用构建产物与 API 夹具验证；Chrome 宿主模拟 `figma.clientStorage`。真实 Figma 客户端里的首次保存、关闭插件再恢复，以及跨设计稿复用，仍待更新后实测，不由浏览器测试代替。内嵌面板测试覆盖运行环境差异，不代表已完成所有 Figma 客户端版本的兼容验证。

真实 Grok 案例验证了矢量图标复刻与导出，不代表完整 UI、字体、Auto Layout、组件变体和每一种原生布尔运算都已完成视觉验收。Node 中的 Figma API 夹具不实现 Figma 几何求解器。

`examples/imagegen-camera-job` 的参考图是真实生图，重建 PNG 是本地矢量预览；该样例尚未作为真实 Figma 导出验收。像素差异和结构检查只能辅助检查，不能单独证明视觉还原质量。

0.6.0 的交互动画在真实 Figma Present 中的播放、中间态和连续操作仍未验证。写入与读回交互、脚本语法通过都不能替代播放验收。
